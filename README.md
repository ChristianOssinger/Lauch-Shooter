# 🧅 Lauch Attack!

Ein lustiges Browser-Spiel als PWA.

## Spielen
👉 [Hier spielen](https://DEIN-USERNAME.github.io/lauch-attack/)

## Installieren (PWA)
- **Android/Chrome**: Menü → "Zum Startbildschirm hinzufügen"
- **iOS/Safari**: Teilen-Button → "Zum Home-Bildschirm"
- **Desktop/Chrome**: Installations-Icon in der Adressleiste

## Steuerung
- 🖱️ Maus → zielen | Klick → schießen
- ⌨️ A/D → drehen | Leertaste → schießen

## Features
- Schiefer Wurf mit Parabel-Vorschau
- Knockback beim Treffer
- Ab Level 5: Teleportation!
